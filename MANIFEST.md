# Package manifest

## Workshop structure

| Folder | Purpose | Notebooks | Main tools |
|---|---|---:|---|
| `00_Start_Here` | Exploit a deliberately vulnerable RAG/tool agent and define the first security contract | 1 | pandas, `demo_agent.py` |
| `01_Threat_Modeling` | Express architecture, trust boundaries, and threats as code; toggle controls | 1 | OWASP `pytm` |
| `02_Prompt_Injection_and_Red_Teaming` | Build a repeatable attack corpus and scale probing against two targets | 2 | pandas, NVIDIA `garak` |
| `03_Agent_Tool_Security` | Typed capabilities, policy, approvals, idempotency between model and tool | 1 | Pydantic |
| `04_Output_Validation_and_Guardrails` | Separate parsing, invariants, content validation, policy, and repair | 1 | Pydantic, Guardrails AI |
| `05_PII_and_Data_Boundaries` | Detect and transform PII into purpose-specific views; measure recall | 1 | Microsoft Presidio + spaCy |
| `06_Evaluations_and_Security_Regression` | Turn red-team findings into deterministic release checks (both agents) | 1 | pytest, Inspect AI |
| `07_Model_Supply_Chain` | Scan serialized artifacts before any deserialization | 1 | ModelScan |
| `08_Observability_and_Incident_Response` | Allow-listed, redacted traces and an incident packet | 1 | OpenTelemetry; optional Phoenix/OTLP |
| `09_Fairness_and_Responsible_AI_Evidence` | Subgroup performance with uncertainty; system card from evidence | 2 | Fairlearn, Hugging Face model cards |
| `10_Capstone_Secure_RAG_Agent` | Combine the controls into an end-to-end release gate | 1 | Pydantic, regression evidence |

**Totals:** 11 topic folders, 13 notebooks, 11 module READMEs (≥ 2 Mermaid diagrams each), all 13
notebooks executed in the pinned environment.

## Evidence and intentionally unsafe samples

`_evidence/` is **generated** by the notebooks (git-ignored except its README) and re-created by
`verify_notebooks.py --mode full`. It includes
`model_artifacts/suspicious_model.pkl`, an intentionally suspicious serialized artifact used only to
demonstrate **scan-before-load**. Do not deserialize it. The ModelScan lab invokes the scanner in a
subprocess and never opens the artifact with `pickle.load`.
