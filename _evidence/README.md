# `_evidence/` — generated workshop outputs

Every notebook writes its evidence here (JSON summaries, garak reports, Inspect `.eval` logs,
ModelScan JSON reports, the synthetic pickles for module 07, the generated system card).

Nothing in this folder except this README is tracked in git: it is fully regenerated by

```bash
python verify_notebooks.py --mode full
```

`model_artifacts/suspicious_model.pkl` is an intentionally unsafe pickle used only to demonstrate
scan-before-load. **Never `pickle.load` it.** Module 07 scans it in a subprocess and never
deserializes it.
